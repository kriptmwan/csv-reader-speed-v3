A faster drop-in for make.fun's csv-reader 1.0.0: it returns exactly the same answers on every input — including broken CSVs (unclosed quotes, stray quotes, embedded newlines, ragged rows, BOM, mixed line endings) — while reading the file with native indexOf scans and whole-line splits instead of one character at a time.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`), answers each with `run()` from `solve.js`, and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
